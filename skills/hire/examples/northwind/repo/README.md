# Northwind Robotics — internal agents

Two agents run day to day. Every agent needs a row here, an entry in `roster.json`,
a job doc under `docs/team/`, and a definition under `.claude/agents/`.

## House rules

- An agent that is not in `roster.json` cannot be dispatched.
- An agent in `roster.json` with no route in the same file breaks routing for everyone.
