What a securitymaxx report looks like

Three demo audits and one blank template. Every scorecard is a single self-contained HTML file — no build step, no JavaScript, no external requests — so it opens straight from disk and survives being emailed.

github.com/jtlgrowth/securitymaxx  ·  MIT

The three audited applications are fictional. They were invented to show what each kind of stack produces — a maintained SaaS, an AI-generated app that shipped without review, and a no-code setup where most checks belong to the vendor. Publishing a real company's failing scorecard would be a different kind of document, and not one worth making.
